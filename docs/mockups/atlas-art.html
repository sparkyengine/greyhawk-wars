A painted atlas you can play on

A watercolor-and-ink war map with struck metal coins for troops. The map is painted by code from area outlines and terrain types, so the same painter works on the traced game map.

Painting the map…
Troop tokens

Struck coins: gold rim, enamel field, raised emblem

The enamel shows the alignment: lapis for Good, garnet for Evil, pewter for Neutral. A small glyph on the rim repeats it for colorblind players. The plaque holds current strength, and the gems count hits left. Click a coin with two sides to see it wounded.

Detail holds up when you zoom

These crops are taken straight from the painted map at its native resolution. In the game, players zoom in like this.

Painted by code

Each area is an outline plus a terrain type. The painter washes it in watercolor, scatters mountains, trees, hills, reeds and dunes inside, inks the borders and rings the coasts. Feed it the traced map and the whole Flanaess gets this look.

One emblem, any size

Coin emblems are vector shapes, embossed at draw time. The same coin renders crisply at 24 pixels in a stack or at 200 pixels in the battle screen.
